# 调研任务：B 站“Vibe 视频”赛道深度调研（用于新账号选定栏目）

## 你的角色
你是一名内容赛道分析师，擅长用**可验证的数据**拆解视频平台的流量规律。你的结论会被直接用来决定一个新账号做什么栏目，所以**准确性远比完整性重要**：宁可写“未查到”，也绝不编造任何数字、账号或视频。

## 背景（请先读懂）
- 委托人想在 **B 站（主阵地）**，以及抖音、视频号、小红书（副阵地）起一个新号，目标是**先流量、后商业化**，越快越好。
- 制作方式：**用代码 + AI（如 Claude 等大模型）生成动画视频**，也就是近期流行的“Vibe 视频”或“Vibe 知识”类视频。
- 委托人的约束：
  - **不出声**：只用 AI 配音，或完全不配音（纯字幕和音乐）；
  - 兴趣领域：**科技、游戏、历史、科学**；
  - 时间：每周约 **20 小时**；
  - 没有视频或 AE 基础，但要求作品水准高，不能做成低级内容。
- **已知的种子样本**：B 站 UP 主「比特新语」（mid: 3494362707135250）。截至 2026 年 10 月中旬，约 **55 万粉丝**，只发了 **18 条视频，几乎全部在 2026 年 10 月这一个月内发布**，单条播放中位数约 **73 万**；每条时长几乎固定在 **2 分 40 秒左右**；分区为“软件应用”；简介含“Vibe 知识大赏：用 AI 把……”。选题把**知识硬核点和人生情绪**绑在一起，例如“看懂了熵增，就原谅了生活所有的力不从心”“「我爱你」说到第 1000 遍，信息量几乎为零”，也做诺贝尔奖等热点。
- **上一轮调研犯过的错误（你必须避免）**：上一轮用“物理模拟”“数据可视化”“尺度对比”等**传统品类关键词**去搜，结果完全漏掉了比特新语这类新现象。新现象往往活在**新的标签、新的分区、新的标题风格**里，用旧分类去找是找不到的。

## 核心研究问题
1. **现象本身**：B 站上“用 AI + 代码做的 Vibe 视频”目前有哪些账号？是哪个时间点开始爆发的？是一个账号的个例，还是一个正在形成的赛道？
2. **成功机制**：这类视频到底靠什么获得流量？要区分以下各个因素的贡献：选题（知识 × 情绪）、标题句式、封面、视觉风格、音乐、时长、发布节奏、热点借势、“AI 做的”这一新鲜感本身、平台扶持（例如分区活动、官方推荐）。
3. **竞争格局**：赛道现在有多拥挤？头部有几个号？新号进入的窗口还剩多久？跟风号的数据怎么样？
4. **可复制性**：在委托人的约束下（不出声、每周 20 小时、兴趣在科技/游戏/历史/科学），哪些做法可以复制？哪些不能复制（例如依赖创作者本人独特文笔或审美的部分）？
5. **差异化机会**：在这个赛道里，有哪些**还没被占据**的选题方向或形式（结合委托人的四个兴趣领域）？

## 调研方法（按顺序执行）

### 第 1 步：从种子出发滚雪球（不要从关键词出发）
- 以「比特新语」为起点，查看：它视频页的“相关推荐”、评论区里被提到的其他 UP 主、评论区里“同类型推荐”的回复、它关注列表中的同类账号。
- 对每个新发现的同类账号，重复上述过程，**至少滚 2 到 3 层**，目标找到 **15 到 30 个同类账号**。
- 补充搜索时，使用**新现象自己的词汇**，而不是传统品类词，例如：“Vibe 知识”“Vibe 视频”“AI 做的视频”“Claude 做的”“Opus 做的”“代码生成视频”“一句话生成视频”“AI 动画 科普”，以及分区“软件应用”“科学科普”下的近期热门。
- 同时检查抖音、小红书、视频号上是否有同一批创作者或同类内容，是否存在**跨平台搬运**的情况（这会揭示内容源头）。

### 第 2 步：对每个账号收集统一的数据
对每个账号，请收集下表的字段。**每一个数字都必须附上来源链接，或注明查看的页面与时间**：

| 字段 | 说明 |
|---|---|
| 账号名、主页链接 | |
| 粉丝数（查看日期） | |
| 首个视频发布日期、投稿总数 | 用来判断起号速度 |
| **最近 20 条投稿的播放量中位数** | **最关键的指标**，代表这个号的“日常水平”，不是最高值 |
| 最高播放、最低播放 | |
| 播放超过 50 万的条数 / 总条数 | 衡量命中率 |
| 平均时长、发布频率 | |
| 是否配音、是 AI 配音还是真人 | 需要实际看视频判断，写明“看过哪几条” |
| 是否标注 AI 生成 | |
| 选题类型、标题句式、封面风格 | 用一句话概括 |
| 涨粉速度 | 如果能从第三方数据站（如飞瓜、新榜、灰豚、B 站数据统计站）查到，请附上 |

### 第 3 步：深度拆解 3 到 5 个代表性视频
从头部账号里挑出：至少 1 条**最高播放**的视频、至少 1 条**播放低于该账号中位数**的视频（用来对比失败原因）。对每条视频：
- **结构拆解**：按时间轴记录，例如 0 到 3 秒做了什么钩子，每一段讲什么，结尾怎么收。
- **视觉拆解**：配色、字体、动画手法（文字动效、粒子、图表、3D）、镜头节奏、平均每个画面停留多久。
- **声音拆解**：音乐风格、是否卡点、有没有配音、配音的语气。
- **文案拆解**：标题、封面文字、视频内文案的句式，例如“知识点 + 人生感悟”的结构。
- **评论区分析**：抽取点赞最高的 20 条评论，归类观众在夸什么、在问什么（尤其是“怎么做的”这类提问的比例）、在吐槽什么。
- **高播放和低播放之间，到底差在哪里？** 这是本步骤最重要的产出。

### 第 4 步：检验“新鲜感溢价”和“平台扶持”
- 这类视频的高播放，有多少来自“AI 做的”这个新鲜感？证据可以来自：评论里有多少在讨论“AI”本身而不是内容；同一个账号随时间推移，播放有没有下降。
- “软件应用”分区是否有官方活动、流量扶持或话题征稿？请查 B 站官方活动页、创作中心公告。
- 跟风号（晚于头部入场的同类账号）的日常中位数是多少？**这个数字比头部数据更能说明新号进入后能拿到什么。**

### 第 5 步：给出候选栏目
基于前四步的证据，给出 **3 到 5 个候选栏目方向**，每个方向都要用下面五条标准评估，并说明证据：
1. **需求**：有多少人想看？
2. **供给缺口**：现有作品够不够多、够不够好？（证据：小粉丝账号是否也能拿到高播放）
3. **代码 / AI 制作优势**：用代码 + AI 来做，是否比别人更好或更快？
4. **选题池深度**：能不能做 100 期？请为每个方向写出 10 个具体选题示例。
5. **与委托人约束的匹配度**：不出声、每周 20 小时、科技/游戏/历史/科学。

另外对每个方向说明：**最大的风险是什么**，以及**如何用 2 到 3 条低成本的测试视频验证它**。

## 证据纪律（必须遵守）
1. **不得编造**：任何你没有实际查到的数字、账号、视频、引语都不能写。查不到就写“未查到”，并说明原因（例如需要登录、被反爬虫拦截）。
2. **区分“观察”与“推断”**：报告中每一条结论，请标注【观察】（直接看到的数据或内容）或【推断】（你的分析判断）。
3. **必须看分母**：禁止只用爆款作为证据。凡是说某个形式“效果好”，必须同时给出相关账号的**日常播放中位数**和**命中率**。
4. **标注时间**：所有数据都要注明查看日期，平台数据会变。
5. **说明局限**：在报告末尾，单独写一节“这份调研没能回答的问题”，以及哪些结论最不可靠。

## 输出格式
1. **一页摘要**：5 条以内的核心结论，每条都附上最关键的一个证据。
2. **账号数据总表**：第 2 步的表格，按日常播放中位数从高到低排序。
3. **代表性视频拆解**：第 3 步的内容，重点写高播放与低播放的差异。
4. **新鲜感与平台扶持的判断**：第 4 步的结论。
5. **候选栏目评估**：第 5 步的内容，包括五条标准的评分、10 个选题示例、风险，以及测试方案。
6. **局限与待验证问题**。
7. **全部来源链接清单**。
